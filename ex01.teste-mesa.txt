Questão 01 – Teste de mesa em algoritmo sequencial
Faça o teste de mesa do algoritmo abaixo, mostrando o valor de cada variável linha a
linha, e informe o que será exibido na tela. Depois, digite e execute no Portugol Studio
para conferir.
inteiro a = 5, b = 3, c
c = a + b * 2
a = c - a
b = a + b
escreva(a, " ", b, " ", c)


(c = a + b * 2) 2 * 3 = 6 + 5 = 11 <- c
(a = c + a) 11 - 5 = 6 <- a
(b = a + b) 6 + 3 = 9 <- b

resultado: 6 9 11
